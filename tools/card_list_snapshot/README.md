# Saved copy of the card list

`cards-list.html` and `mystyles.css` are the fan-made card list page
(https://ssimeonoff.github.io/cards-list) and its stylesheet (`/css/mystyles.css`), by
ssimeonoff (github.com/ssimeonoff/ssimeonoff.github.io, BSD-3-Clause). First saved on
2026-10-23; the page itself was last changed on 2025-11-10.

`uv run python -m tools.card_import` parses them into `engine/cards/cards.json`, and
`--download` saves them again (the git history shows when). Don't edit them by hand.

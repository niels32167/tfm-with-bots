# Browser GUI modelled on Board Game Arena's Terraforming Mars

The GUI runs in the browser, is built with React and TypeScript, and copies the layout of Board Game Arena's Terraforming Mars as closely as possible, because that is the adaptation the user likes best. A screenshot of the official Asmodee digital game is a second reference for the board and its tracks.

The Mars globe comes from free NASA imagery; Areas, placement bonuses and Tiles are drawn by the GUI. On top of the polished view sits a dev panel that can be toggled on, for checking the rules: game log, seed, undo, save/load, replay and a state editor.
